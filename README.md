## 🟡 Level 2 – Core Python & Logic Building

- **Task_1.py**  
  Implements a basic number guessing game with user feedback.

- **Task_2.py**  
  A number guessing game with a user-defined range and replay option.

- **Task_3.py**  
  Evaluates password strength based on length and character rules.

- **Task_4.py**  
  Generates the Fibonacci sequence for a given number of terms.

- **Task_5.py**  
  Reads a text file and counts word occurrences in alphabetical order.
